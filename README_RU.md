# 🎙 LessonRecorder

> Записывай урок — получай готовый конспект. Автоматически.

---

## Что умеет программа

- **Записывает** звук с микрофона или системного аудио (захватывает онлайн-уроки, вебинары, лекции)
- **Распознаёт** речь без интернета — модель Whisper работает прямо на твоём компьютере
- **Составляет конспект** через бесплатный ИИ — структурированный, с заголовками и выводами
- **Хранит историю** всех уроков с поиском и экспортом в файл
- **Обновляется сам** — при выходе новой версии предложит обновиться в один клик

## Для инженеров / рецензентов

**Пайплайн:** `recorder` (микрофон + WASAPI loopback) → `transcriber` → опционально `photo_ocr` → `summarizer`, всё это связано в GUI-оболочке на PyQt6 (`ui/`).

Транскрипция (`core/transcriber.py`, `core/transcribe_worker.py`) выполняется в **отдельном subprocess**, а не в основном процессе. Причина: нативный бэкенд ctranslate2 у `faster-whisper` может жёстко уронить процесс на некоторых CPU (проблемы AVX2/native) без перехватываемого исключения Python — см. `NATIVE_CRASH_CODES` в `core/transcriber.py`. Изоляция в отдельном воркере превращает такой краш в обычный код завершения процесса, который приложение может перехватить и прозрачно повторить попытку через `openai-whisper`, не роняя весь GUI.

Модуль конспектов (`core/summarizer.py`) не завязан на одного поставщика LLM — это словарь `PROVIDERS`, описывающий каждый бэкенд (base URL, модели, авторизация) за одним OpenAI-совместимым HTTP-клиентом. Это осознанное решение: пользователь в любом регионе может выбрать провайдера, который реально доступен и по карману именно ему, вместо того чтобы приложение становилось бесполезным, как только один API заблокирован, лимитирован или слишком дорог.

**GigaChat (Сбер) — полноценный провайдер**, а не довесок для галочки: авторизация идёт через собственный OAuth Сбера (`client_id`/`secret` → bearer-токен, `https://gigachat.devices.sberbank.ru/api/v1`), есть бесплатный тариф 150 000 токенов/мес, и он был добавлен намеренно — чтобы приложение поддерживало не только зарубежные LLM, но и собственную модель Сбера наравне с ними.

Технологический стек:
- **PyQt6** — десктопный интерфейс
- **openai-whisper** / **faster-whisper** — офлайн-распознавание речи, с изоляцией в subprocess и автоматическим фолбэком между движками
- **sounddevice** + **scipy** — кроссплатформенный аудио-ввод/вывод, плюс WASAPI loopback для записи системного звука на Windows
- **pytesseract** + **OpenCV** — OCR фотографий доски/слайдов
- OpenAI-совместимый клиент на **requests** — единым кодом обращается к DeepSeek, GigaChat, Groq, Gemini, OpenRouter или любому кастомному эндпоинту

Тесты: `pip install -r requirements-dev.txt && pytest`

## Установка

### Windows

1. Перейди в раздел [Releases](../../releases)
2. Скачай файл `LessonRecorder_vX.X.X_Windows_setup.exe`
3. Запусти — установщик сам скачает Python и все компоненты
4. Готово, запускай из меню Пуск

> Python устанавливать отдельно **не нужно** — всё происходит автоматически

### macOS

1. Скачай `LessonRecorder_vX.X.X_macOS.dmg`
2. Открой DMG и перетащи иконку в папку Программы
3. При первом запуске: **правая кнопка → Открыть → Открыть**

> Если Python не установлен, один раз запусти `./mac_setup.sh` из папки проекта — он сам поставит Homebrew и Python, вручную ничего делать не нужно. (Отдельного macOS-инсталлятора с post-install хуком пока нет, поэтому это разовый ручной запуск скрипта, а не полностью тихая установка, как в Windows `.exe` — подробнее в разделе для инженеров выше.)

### Linux

1. Скачай `LessonRecorder_vX.X.X_Linux.AppImage`
2. Сделай файл исполняемым и запусти:

```
chmod +x LessonRecorder_*.AppImage
./LessonRecorder_*.AppImage
```

## Первый запуск

### Транскрипция (работает без интернета)

Открой **Настройки → Транскрипция** и выбери модель:

| Модель | Скорость | Качество | Подходит для |
|--------|----------|----------|--------------|
| `tiny` | ⚡ Очень быстро | Хорошее | Быстрые заметки, чёткое аудио |
| `base` | Быстро | Лучше | **Рекомендуется** |
| `small` | Средне | Отлично | Важные лекции |
| `medium` | Медленно | Превосходно | Максимальное качество |

Модель скачивается один раз при первом использовании.

### ИИ-конспект (нужен интернет, бесплатно)

Открой **Настройки → ИИ провайдер** и выбери один:

| Провайдер | Лимит | Регистрация |
|-----------|-------|-------------|
| **DeepSeek** ✅ РФ | Очень дёшево (~$1 на месяцы) | [platform.deepseek.com](https://platform.deepseek.com) |
| **GigaChat (Сбер)** ✅ РФ | 150 000 токенов/мес бесплатно | [developers.sber.ru](https://developers.sber.ru/studio) |
| **Groq** | 14 400 запросов/день | [console.groq.com](https://console.groq.com) |
| **Google Gemini** | 250 запросов/день | [aistudio.google.com](https://aistudio.google.com) |

Карта не нужна ни для одного из них. Вставь ключ → **Проверить соединение** → Сохранить.

## Как пользоваться

1. Открой вкладку **Запись**
2. Выбери источник звука: Микрофон / Системный звук / Оба
3. Нажми **Начать запись**
4. Когда закончишь — нажми **Стоп**. Транскрипция запустится сама
5. После распознавания нажми **Создать конспект**
6. Все уроки сохраняются во вкладке **История**

---

## Советы

- Используй **«Оба источника»** на онлайн-уроках — запишет и себя, и преподавателя
- Первая транскрипция занимает ~30 секунд (загрузка модели), все следующие — мгновенно
- Добавляй **фотографии доски или слайдов** через кнопку 📷 — текст с них попадёт в конспект
- Если Groq недоступен в твоём регионе — используй GigaChat или DeepSeek
