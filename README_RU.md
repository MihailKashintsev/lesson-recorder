# 🎙 LessonRecorder

> Записывай урок — получай готовый конспект. Автоматически.

---

## Что умеет программа

- **Записывает** звук с микрофона или системного аудио (захватывает онлайн-уроки, вебинары, лекции)
- **Распознаёт** речь без интернета — модель Whisper работает прямо на твоём компьютере
- **Составляет конспект** через бесплатный ИИ — структурированный, с заголовками и выводами
- **Хранит историю** всех уроков с поиском и экспортом в файл
- **Обновляется сам** — при выходе новой версии предложит обновиться в один клик

---

## Установка

### Windows

1. Перейди в раздел [Releases](../../releases)
2. Скачай файл `LessonRecorder_vX.X.X_Windows_setup.exe`
3. Запусти — установщик сам скачает Python и все компоненты
4. Готово, запускай из меню Пуск

> Python устанавливать отдельно **не нужно** — всё происходит автоматически

### macOS

1. Скачай `LessonRecorder_vX.X.X_macOS.dmg`
2. Открой DMG и перетащи иконку в папку Программы
3. При первом запуске: **правая кнопка → Открыть → Открыть**

> При необходимости: `brew install python3`

### Linux

1. Скачай `LessonRecorder_vX.X.X_Linux.AppImage`
2. Сделай файл исполняемым и запусти:

```
chmod +x LessonRecorder_*.AppImage
./LessonRecorder_*.AppImage
```

## Первый запуск

### Транскрипция (работает без интернета)

Открой **Настройки → Транскрипция** и выбери модель:

| Модель | Скорость | Качество | Подходит для |
|--------|----------|----------|--------------|
| `tiny` | ⚡ Очень быстро | Хорошее | Быстрые заметки, чёткое аудио |
| `base` | Быстро | Лучше | **Рекомендуется** |
| `small` | Средне | Отлично | Важные лекции |
| `medium` | Медленно | Превосходно | Максимальное качество |

Модель скачивается один раз при первом использовании.

### ИИ-конспект (нужен интернет, бесплатно)

Открой **Настройки → ИИ провайдер** и выбери один:

| Провайдер | Лимит | Регистрация |
|-----------|-------|-------------|
| **DeepSeek** ✅ РФ | Очень дёшево (~$1 на месяцы) | [platform.deepseek.com](https://platform.deepseek.com) |
| **GigaChat (Сбер)** ✅ РФ | 150 000 токенов/мес бесплатно | [developers.sber.ru](https://developers.sber.ru/studio) |
| **Groq** | 14 400 запросов/день | [console.groq.com](https://console.groq.com) |
| **Google Gemini** | 250 запросов/день | [aistudio.google.com](https://aistudio.google.com) |

Карта не нужна ни для одного из них. Вставь ключ → **Проверить соединение** → Сохранить.

## Как пользоваться

1. Открой вкладку **Запись**
2. Выбери источник звука: Микрофон / Системный звук / Оба
3. Нажми **Начать запись**
4. Когда закончишь — нажми **Стоп**. Транскрипция запустится сама
5. После распознавания нажми **Создать конспект**
6. Все уроки сохраняются во вкладке **История**

---

## Советы

- Используй **«Оба источника»** на онлайн-уроках — запишет и себя, и преподавателя
- Первая транскрипция занимает ~30 секунд (загрузка модели), все следующие — мгновенно
- Добавляй **фотографии доски или слайдов** через кнопку 📷 — текст с них попадёт в конспект
- Если Groq недоступен в твоём регионе — используй GigaChat или DeepSeek
